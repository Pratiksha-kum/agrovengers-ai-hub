# 🌾 AgroVengers - Cropwise AI AgentHub

Complete Farm Intelligence Platform powered by AI

## Live Demo
https://agrovengers-hack.vercel.app

## Tech Stack
- Next.js 14, React 19, TypeScript
- Groq AI SDK (LLaMA 3 70B)
- Tailwind CSS, shadcn/ui
- Vercel Deployment

## Features
- 10 Specialized AI Agents
- Multilingual (English, Hindi, Marathi)
- Voice AI Assistant
- Disease Detection
- Mandi Price Intelligence
- Crop Rotation Planning
- Sustainability Tracking
- FairTrade Guardian

## Setup
```bash
npm install --legacy-peer-deps
npm run dev
```

Then push the README:

```powershell
git add README.md
git commit -m "Add README"
git push
```
